# FTA示例：仅作方法演示

以下为虚构研究设定，不能当作用户实际成果。候选问题：多源资料中的事件与关系不一致，使自动建树难以追溯。候选机制：多模态对齐、知识统一及规则约束。

| 候选主张 | 验证设计 | 评价口径与限制 |
|---|---|---|
| 提升事件与关系抽取 | 固定测试资料，与人工流程或适配基线比较 | 分别计算实体/关系P、R、F1；先定义匹配准则 |
| 多模态对齐有贡献 | 去除对齐，保持其他设置一致 | 有人工匹配真值时评价匹配准确率 |
| 知识统一改善一致性 | 去除术语统一，使用同源划分 | 评价规范实体映射，不仅统计合并数量 |
| 增强证据可追溯性 | 去除证据锚点机制 | 锚点覆盖率与有效性分别检查；有锚点不等于证据正确 |
| 改善故障树逻辑 | 去除规则约束，与专家标注对照 | 规则符合率、因果/门关系正确性分开评价 |

最小验证：选一份有图表及文本的公开或获授权资料，定义事件、关系、锚点输出；检查抽取、对齐、合并和建树输入。没有专家真值时只能报告流程表现和规则检查，不宣称故障树正确。完整树评价须定义顶事件、边界、事件粒度与逻辑门标准。

调用示例：
- “根据研究设想，生成主张与实验对应表，不把设想写成成果。”
- “这是五次运行记录，整理日志，缺少的配置标为未知。”
- “拆解这篇论文的研究缺口和实验论证，标出原文位置。”
- “总体F1变化小，按实体和关系类型分析错误，提出最小验证实验。”
